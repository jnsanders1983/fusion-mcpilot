# Contributing

Use supported native Fusion functionality before implementing substitutes. Research authoritative documentation and inspect current schemas; demonstrate a gap before adding a custom exporter or protocol adapter. Keep a clear contract and representative independent validation.

Run the offline tests and packaging command in the README. Never run live modifying tests in a user's active production document: use explicit disposable documents and checkpoint before risky changes. Report Fusion version, operating system, server contract, recipe, chosen parameters and scoped timings; redact private paths, names, tokens and credentials.

Keep helpers reusable and references concise. Add a regression for a meaningful failure. Distinguish tests from user observations; do not claim all paid features or agent hosts are tested. Update installation guidance when integration behavior changes. Do not commit CAD projects, research clones, raw API responses, crash reports or execution logs.
